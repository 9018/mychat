# Vox Collage Executive Producer

Use this pipeline when the deliverable is a beat-driven paper collage montage with generated keyframes, real short motion clips and narration.

The canonical state machine is `research -> proposal -> script -> scene_plan -> assets -> edit -> compose -> publish`. The agent must read the stage director before each stage, run registry preflight, checkpoint every stage, and stop at human gates.

The pipeline is motion-required when the brief depends on moving generated clips. In that case do not silently replace clips with Ken Burns stills. If the approved provider or runtime is unavailable, report the blocker and request a decision.
